# CodeAlpha Data Analytics Internship Project

This project was completed as part of the CodeAlpha Data Analytics Internship.

## Tasks Completed

### 1. Web Scraping

* Scraped book data from the website using Python
* Extracted:

  * Book Title
  * Price
  * Rating
* Stored data into CSV format

### 2. Exploratory Data Analysis (EDA)

* Analyzed dataset using Pandas
* Found:

  * Highest Price
  * Lowest Price
  * Average Price
  * Rating Counts

### 3. Data Visualization

* Created rating distribution graph using:

  * Matplotlib
  * Seaborn

### 4. Sentiment Analysis

* Performed sentiment analysis on sample reviews
* Classified reviews into:

  * Positive
  * Negative
  * Neutral

## Technologies Used

* Python
* Pandas
* BeautifulSoup
* Requests
* Matplotlib
* Seaborn
* TextBlob
